# 建议使用哪三个模型

你们原计划是：

- Logistic Regression
- Decision Tree
- Random Forest

我认为可以保留，而且很适合这个 Assignment。

最终形成：

## Model 1 — Multinomial Logistic Regression

作为：

> Baseline Model

优点：

- 简单
- 可解释
- 适合 multiclass classification
- 作为复杂模型比较基准

------

## Model 2 — Decision Tree

作为：

> Interpretable Non-linear Model

优点：

- 可以捕捉非线性关系
- 容易可视化
- 适合 Presentation
- 可以展示 decision rules

------

## Model 3 — Random Forest

作为：

> Ensemble Model

优点：

- 比单棵 Decision Tree 更稳定
- 降低 overfitting
- 可以处理复杂 feature interactions
- 可以输出 feature importance

最终 Q4 的故事非常清晰：

```
Logistic Regression
        ↓
Simple Linear Baseline

Decision Tree
        ↓
Single Non-linear Model

Random Forest
        ↓
Ensemble of Multiple Trees
```

这三个模型不是随机选择的，而是有递进关系。
